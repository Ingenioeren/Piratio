# Pirat.io

A fast top-down pirate arena game for Android, inspired by the short-session growth loop of .io games.

## Prototype v0.1

The first playable build focuses on the core loop:

- Sail a pirate ship using a virtual joystick
- Fire left/right broadsides
- Destroy AI ships and collect their loot
- Collect floating treasure around the map
- Grow through five ship tiers during a run
- Compete against bots on an always-visible leaderboard
- Sink, respawn, and climb again

The prototype is deliberately local/single-player-with-bots first. Networking will be introduced after the movement, combat and growth loop feels good.

## Planned direction

1. Tune core movement, combat and ship growth
2. Improve art, VFX, sound and map features
3. Add authoritative online multiplayer and matchmaking
4. Add cosmetics, persistent progression and accounts
5. Add rewarded ads and carefully limited interstitial ads
6. Add analytics, retention tuning and store release tooling

## Build

Open the project in Android Studio and run the `app` configuration, or use the included GitHub Actions workflow to build a debug APK.

Minimum Android version: Android 7.0 (API 24).
